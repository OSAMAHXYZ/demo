GEC CONTROL · status rules

Visitor · Lead · Conversion

Every GEC record is classified by its Status — first enabled match of Conversion → Lead → Visitor (upper/lower case ignored). Visitor statuses are registrations, not leads. Conversion statuses count as converted and still count as leads. A status in no list counts as a lead and is flagged under Attention on the dashboard until you classify it here.

BO Error Condition

Order errors pushed to employees

Same conditions as the BO error rules in Reserved Orders admin. Put any condition on the current Back Order file, Test it to see the errors per employee, then Push the rule.
