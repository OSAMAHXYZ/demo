Section 1 All Stock Matching Class

Purpose: FIFO allocation of Back Orders against available stock using color dictionaries and specification matching.

Process Flow

flowchart TD
  ED["ExteriorColorDictionary"] --> CLEANBO["Clean BO Data"]
  ID["InteriorColorDictionary"] --> CLEANBO
  CLEANBO --> EXBO["Extract Exterior Code"]
  EXBO --> INBO["Extract Interior Code"]
  INBO --> CLEANS["Clean Stock Data"]
  CLEANS --> EXST["Extract Stock Codes"]
  EXST --> FIFO["FIFO Sort"]
  FIFO --> GRP["Group + Index"]
  GRP --> MERGE["FIFO Merge"]
  MERGE --> OUT["Matched VIN Output"]
1 Load Exterior Color Master
Source: ExteriorColorDictionary. Read ColorCode, trim spaces, convert to uppercase, sort descending.
2 Load Interior Color Master
Source: InteriorColorDictionary. Read ColorCode, trim spaces, convert to uppercase, sort descending.
3 Clean BO Data
Normalize Product, Alj Suffix, Exterior Color, Interior Color. Remove spaces and hyphens. Convert text to uppercase.
4 Generate Color Codes
  • ExteriorCode = first matching code from ExteriorMaster
  • InteriorCode = first matching code from InteriorMaster
5 Clean Stock Data
Normalize the same fields on stock as on BO.
6 Generate Stock Codes
Create ExteriorCode and InteriorCode on stock rows.
7 FIFO Logic
Sort BO by Order Date ascending. Sort Stock by VIN ascending.
8 Grouping
Group by Product, Alj Suffix, ExteriorCode, InteriorCode. Add BO_Index and Stock_Index.
9 FIFO Matching
Match on Product + Alj Suffix + ExteriorCode + InteriorCode + Index.
10 Output
Expand stock information and keep matched VINs only. Expected: FIFO matched inventory table.
Power Query · All Stock Matching Class (conceptual)M
// Color masters
let
  ExteriorMaster = Table.TransformColumns(
    ExteriorColorDictionary,
    {{"ColorCode", each Text.Upper(Text.Trim(_)), type text}}
  ),
  InteriorMaster = Table.TransformColumns(
    InteriorColorDictionary,
    {{"ColorCode", each Text.Upper(Text.Trim(_)), type text}}
  ),
  CleanBO = /* normalize Product / Suffix / colors */ ...,
  WithCodes = /* ExteriorCode & InteriorCode from masters */ ...,
  SortedBO = Table.Sort(WithCodes, {{"Order Date", Order.Ascending}}),
  SortedStock = Table.Sort(CleanStock, {{"VIN", Order.Ascending}}),
  Indexed = /* group + BO_Index / Stock_Index */ ...,
  Matched = Table.NestedJoin(IndexedBO, {"Product","Alj Suffix","ExteriorCode","InteriorCode","BO_Index"}, IndexedStock, {"Product","Alj Suffix","ExteriorCode","InteriorCode","Stock_Index"}, "Stock", JoinKind.Inner)
in
  Matched

Section 2 Daily Stock Matching

Purpose: Daily validation of stock against BO requirements — BO match, VIN uniqueness, and RTL stock presence.
flowchart TD
  S["all stock"] --> SEL["Select Columns"]
  SEL --> REN["Rename ALJ Suffix"]
  REN --> CLN["Clean Text"]
  CLN --> COD["Extract Color Codes"]
  COD --> JOIN["Join BO+ fleetBO"]
  JOIN --> EXP["Expand BO Data"]
  EXP --> ST["Create Match Status"]
  ST --> NULLS["Force Null Values"]
  NULLS --> DEDUP["Remove Duplicate VIN"]
  DEDUP --> RTL["RTL Inventory Check"]
  RTL --> FINAL["Final Dataset"]
1 Load all stock
Keep: VIN, Product, ALJ Suffix, Model Year, Exterior Color, Interior Color, Current Location, Secondary Status, Storage Location, Sharing Level.
2 Rename
ALJ Suffix → Alj Suffix
3 Normalize
Uppercase, trim spaces, convert Model Year to text.
4 Extract Codes
Exterior = last word from Exterior Color. Interior = last word from Interior Color.
5 BO Matching
Join on Product, Model Year, Alj Suffix, Exterior Code, Interior Code against BO+ fleetBO.
6 Expand
Salesman Name, Back Order Number, Order Date, Confirm Flag, Cust Group, DPR, المبلغ المدفوع, Grade (VC).
7 Match Status
If BO exists → Matched. Else → No BO.
8 Force Null Fields
When No BO, force Salesman Name, Back Order Number, Order Date, Confirm Flag, Cust Group, DPR, المبلغ المدفوع, Grade (VC) to NULL.
9 Remove Duplicate VINs
Enforce VIN uniqueness.
10 RTL Validation
Compare VIN against المخزون المتاح All Retail. Create RTL Stock matched = In Stock or Not in RTL Stock. Output: enriched daily stock dataset.
Power Query · Daily Stock Matching (conceptual)M
let
  Source = AllStock,
  SelectCols = Table.SelectColumns(Source, {"VIN","Product","ALJ Suffix","Model Year","Exterior Color","Interior Color", ...}),
  Renamed = Table.RenameColumns(SelectCols, {{"ALJ Suffix", "Alj Suffix"}}),
  Cleaned = /* Text.Upper / Text.Trim / Model Year as text */ ...,
  WithCodes = Table.AddColumn(Cleaned, "Exterior Code", each List.Last(Text.Split([Exterior Color], " "))),
  Joined = Table.NestedJoin(WithCodes, {"Product","Model Year","Alj Suffix","Exterior Code","Interior Code"}, BOFleetBO, {...}, "BO", JoinKind.LeftOuter),
  Status = Table.AddColumn(Expanded, "BO Match", each if [Back Order Number] <> null then "Matched" else "No BO"),
  Dedup = Table.Distinct(Nulled, {"VIN"}),
  RTL = Table.AddColumn(Dedup, "RTL Stock matched", each if List.Contains(RetailVINs, [VIN]) then "In Stock" else "Not in RTL Stock")
in
  RTL

Section 3 Full Control Validation

Purpose: Validate BO quantities against available retail stock and produce an allocation control report.
flowchart TD
  BO["BO+ fleetBO"] --> CLEAN["Clean Data"]
  CLEAN --> FIFO["FIFO Logic"]
  FIFO --> RTL["Retail Stock Matching"]
  RTL --> VAL["Match Validation"]
  VAL --> CBO["Count BO"]
  CBO --> CST["Count Available Stock"]
  CST --> QTY["Quantity Check"]
  QTY --> RPT["Control Report"]
1 Clean BO Data
Normalize Product, Alj Suffix, Model Year, Exterior Color, Interior Color.
2 Clean Retail Stock
Source: المخزون المتاح All Retail. Normalize the same key fields.
3 FIFO Sort
BO by Order Date ASC. Stock by Vehicle Identification Number ASC.
4 Grouping
Build BO_Grouped and Stock_Grouped with BO_Index / Stock_Index.
5 FIFO Merge
Match by Product, Alj Suffix, Model Year, Exterior Color, Interior Color, Index.
6 Add Match Found
YES / NO flag per allocation attempt.
7 Count Available Stock
Compute Available Stock Count per key.
8 Count BO
Compute BO Count per key.
9 Quantity Validation
  • BO Count = null → NO BO
  • Available Stock Count = null → NO STOCK
  • BO Count > Available Stock Count → BO > STOCK
  • BO Count < Available Stock Count → STOCK > BO
  • Otherwise → BALANCED
Output: Allocation Control Report.
Power Query · Full Control Quantity StatusM
Table.AddColumn(Counts, "Quantity Status", each
  if [BO Count] = null then "NO BO"
  else if [Available Stock Count] = null then "NO STOCK"
  else if [BO Count] > [Available Stock Count] then "BO > STOCK"
  else if [BO Count] < [Available Stock Count] then "STOCK > BO"
  else "BALANCED"
)
